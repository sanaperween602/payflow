# PayFlow

PayFlow is a full-stack payment application that allows users to create accounts, authenticate securely, view their account balance, search for other users, and transfer money between accounts.

## 🚀 Features

- User Signup and Signin
- JWT-based authentication
- User search
- Account balance management
- Money transfer between users
- MongoDB database
- RESTful APIs
- Responsive frontend

## 🛠️ Tech Stack

### Frontend
- React
- TypeScript
- React Router
- Tailwind CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- Zod
